Add a job

A name is all it takes — the rest is optional. Print time is what the slicer said, typed in as “2h 30m”, “150” (minutes), “2.5h”, or “45m” — the app never estimates a time or a cost. Blank time or cost means unknown, and the totals say so instead of guessing.

Summary

Queued time and cost add up only the jobs that have a time or a cost entered — a job with no time or cost entered carries none in the totals, and the summary counts it as unknown instead of guessing.

Bikes

Bikes live in the shared Pocket Garage roster — the same b1/b2/b3 list the other apps use. Add a bike here and it is added to that roster for every app. There is no delete-bike here: roster management belongs to the landing dashboard, so a mistyped bike is removed there, not here.

Your data

No account, no server, no sync. Your queue lives in this browser's local storage. Back it up with Export — one JSON file.

Export

The backup is the whole print queue — every bike, every job. The per-bike export below is one bike's jobs, as JSON or readable plain text.

Import

Import replaces the current print queue. Export first if you want to keep it. Jobs pointing at a bike the shared roster doesn't have yet still load — they show under their roster key until that bike is added.

Try it out

Loads example jobs in the queue so you can see the order, the status buttons, and what a job without a time or cost does to the totals — before entering your own jobs. The example times and costs are example figures only.

Delete clears this app's jobs only. The shared bike roster is not touched.
